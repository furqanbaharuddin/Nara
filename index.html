Kepribadian & ingatan

Suara

Kalau tidak ada suara Indonesia: iPhone → Pengaturan → Aksesibilitas → Konten Lisan → Suara → Indonesia. Mac → System Settings → Accessibility → Spoken Content.
Perbesar kalau Nara sering memotong; perkecil kalau terasa lambat menanggapi. Atau akhiri kalimat dengan "sudah" / "udah" / "selesai" supaya Nara langsung menjawab.
Potong dengan suaraNara berhenti bicara begitu Anda mulai bicara. Nyalakan hanya saat memakai earphone; tanpa earphone dia akan mendengar suaranya sendiri.
Laporan pagi otomatisSekali sehari saat Nara dibuka, dia menyiapkan ringkasan: omzet kemarin, yang belum absen, tagihan belum lunas, dan booking hari ini. Muncul sebagai teks; bilang "bacakan" untuk mendengarnya.
Bacakan jawaban di mode ketik

Keamanan

Belum dikunci. Siapa pun yang memegang perangkat ini bisa memakai Nara.

Dengan kunci aktif, API key dan kunci kasir disimpan terenkripsi dan hanya terbuka lewat Face ID atau PIN. Nara mengunci sendiri setelah 5 menit tidak dipakai.

Usulan perubahan untuk Claude

Nara hanya membaca dan menjelaskan; dia tidak bisa mengubah SOP, harga, atau data. Setiap permintaan perubahan dia catat di sini. Tekan Salin, lalu tempel ke obrolan dengan Claude untuk dibahas dan dibuatkan.
